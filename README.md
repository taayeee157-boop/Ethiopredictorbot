
# EthiopredictorBot 🇪🇹 - Football Prediction Bot

**AI-Powered Football (Soccer) Prediction Bot** built by an Ethiopian Software Developer.

This bot uses Machine Learning to predict match outcomes, over/under goals, BTTS, and more.

## Features
- Predicts match results (Win/Draw/Loss)
- Over/Under 2.5 goals predictions
- Both Teams To Score (BTTS)
- Data scraping from football sources
- Model training and evaluation
- Automated predictions

## Technologies Used
- Python
- Pandas & NumPy
- Scikit-learn
- (Add more: TensorFlow, BeautifulSoup, Requests, etc.)
- Machine Learning algorithms (Random Forest, XGBoost, etc.)
